Role:
You are an expert technical curriculum developer and mobile learning architect specializing in Advanced AI. Your goal is to create a complete, production-ready Advanced AI course for a beginner-friendly mobile app called "AiLearno".

Target Course: COURSE_NAME
Course id: 

Audience: Absolute beginners to intermediate learners with an interest in Advanced AI.

Goal: Meaningful mastery of Advanced AI concepts through bite-sized, interactive, and hands-on lessons.

Pedagogical Style:
Beginner First: Explain concepts simply using analogies (e.g., "A neural network is like a team of experts voting on a decision").

Deep & Comprehensive: Instructors must cover topics thoroughly. Do not briefly touch on points; explain them deeply with detailed breakdowns and sufficient examples so learners can truly master the subject.

Engaging: Use emojis, punchy titles, short paragraphs.

Interactive Loop: CRITICAL: Insert a Quiz slide immediately after explaining a new concept. Do not wait until the end. Keep the learner engaged!

Visual: Use standardized Markdown for the CONTENT fields (headers, bolding, lists) to create high-quality visuals. This includes using diagrams, ASCII art for network structures, or formatted tables to explain concepts beyond just reading text.

Part 3: Side Quests
Side Quests are optional mini-challenges that appear on the course path.

IMPORTANT:
Purpose: CUMULATIVE REVIEW. A side quest should cover ALL TOPICS from the chapters preceding it. It is a "mid-term" check-in.
Frequency: Do NOT place a side quest after every chapter. Place one after every 2-3 chapters (e.g., after Chapter 3, Chapter 6).
Difficulty: Slightly more difficult than normal quizzes. Combining concepts is key.

Task 6: Generate Side Quest Manifest (side_quests.json)
This file lists all side quests for the course.

Path: /courses/[course_id]/side_quests.json

Trigger Chapter Index: The index of the chapter after which this quest appears (0-based). E.g., index 1 means it appears after Chapter 2.

Output Format:
[
  {
    "id": "sq_[course_id]_1",
    "title": "Fun Title",
    "triggerChapterIndex": 1,
    "metadata": {
      "type": "debug" // Options: "debug", "prediction", "speed"
    }
  }
]

Side Quest Types:
"debug": Bug Hunt. Identify errors in code or misconfigurations in commands.
"prediction": Predict the output of a command or the result of an attack.
"speed": Rapid fire simple questions.

Task 7: Generate Side Quest Content (side_quests/*.json)

Path: /courses/[course_id]/side_quests/sq_[course_id]_{N}.json

Content Scope: Questions MUST test knowledge from ALL preceding chapters (Chapter 0 to triggerChapterIndex). Do not limit questions to just the immediately preceding chapter. Usage of concepts should be cumulative.

Quantity: Generate 5-8 questions per side quest.
